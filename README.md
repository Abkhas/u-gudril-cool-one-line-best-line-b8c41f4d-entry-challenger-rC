A challenger entry for make.fun's "One Line, Best Line" bounty: one sentence, no more than 240 characters, meant to be read once and remembered. The prize pool is $5 in USDC plus collected entry fees.

How it works: running `main.py` drops the chosen sentence into `entry.txt` inside the output directory, then reads the file back to make sure every character survived.

> I have watered my neighbour's plastic plants for six years, because she died in 2019 and I never had the heart to tell them.
